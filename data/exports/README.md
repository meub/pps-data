# PPS data exports

Plain CSVs generated by `scripts/export_enrollment_by_grade.py`. Regenerate
with `.venv/bin/python scripts/export_enrollment_by_grade.py`.

## pps_enrollment_by_grade_2022-23_to_2025-26.csv

Students enrolled on the first school day in October, by school and grade,
for every Portland SD 1J school in the Oregon Department of Education (ODE)
Fall Membership Reports for 2022-23, 2023-24, 2024-25, and 2025-26.

One row per school per school year.

| Column | Meaning |
|---|---|
| `school_year` | 2022-23 to 2025-26 |
| `ode_school_id` | ODE institution ID; stable across years and renames |
| `school_name` | Name as printed in that year's ODE file |
| `school_name_2025_26` | Name in the 2025-26 file, for joining across years (blank if the school no longer reports) |
| `school_type` | ODE school type (blank in 2022-23, which lacks the column) |
| `level` | elementary, k8, middle, high, alternative, other; blank for contracted and charter programs outside this dashboard |
| `k`, `g1` ... `g12` | Students in each grade |
| `total_k12` | Sum of the grade columns; equals ODE's school total |
| `scenario_a`, `scenario_b` | What PPS's Oct 2026 draft rightsizing scenarios do to the school: `closes`, `program_change` (a program or grade band moves in or out), `boundary`, or blank for no change |
| `note` | Known data caveats |

Checks: each school's grades sum to ODE's school total, and the schools sum
to ODE's district total every year (44,681 / 43,979 / 43,319 / 42,623).

Caveats:

- Hayhurst's counts include the Odyssey Program (K-8). ODE reports Odyssey
  under Hayhurst's ID even though Odyssey has been in the East Sylvan
  building since fall 2016, and no public source splits them by grade.
  PPS's own totals (PSU forecast) put Hayhurst at 290 and Odyssey at 217
  in fall 2025.
- Older files print "-" for a grade with no students; these are 0 here.
- ODE's 2024-25 file lists two contracted programs twice under one ID, once
  with zero students; the empty duplicate is dropped.
- Counts are by school, not by program. A school with a dual language
  immersion strand reports one number per grade covering both strands.

## pps_rightsizing_receiving_schools.csv

For each school that closes in PPS's draft Scenario A or B (October 2026),
the schools that would receive its students, which students go where, and
PPS's proposed split where one is given. Transcribed from PPS's board memo
for the October 6, 2026 meeting (`data/raw/pps_rightsizing_board_2026-10-06/`),
because the scenario comparison document does not name receiving schools.
